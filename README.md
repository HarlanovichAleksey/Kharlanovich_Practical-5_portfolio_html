# Практическая работа №5 — адаптивный сайт-портфолио

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Адаптивный сайт-портфолио с добавленным **таймером обратного отсчёта до конца дня**.
Взаимодействие с HTML реализовано через **чистый JavaScript (DOM)** без использования библиотек.

## Что реализовано
- **Фиксированное меню** с якорными ссылками (`Главная`, `Портфолио`, `Контакты`);
- **Hero-секция** с фотографией, именем, описанием и кнопками;
- **Таймер обратного отсчёта** в шапке сайта (выводит часы, минуты и секунды до 23:59:59);
- **Секция портфолио** — три карточки реальных проектов через CSS Grid;
- **Секция контактов** — Telegram, Max, ВКонтакте с иконками Font Awesome;
- **Плавный скролл** (`scroll-behavior: smooth`);
- **Нативные CSS-анимации** — вращение логотипа, hover-эффекты кнопок;
- **Библиотечные анимации** — Animate.css + WOW.js (появление элементов при скролле);
- **Адаптив** от 1200px до 300px — с сохранением боковых отступов.

## Работа с DOM (Тема 5)
- Создан отдельный файл `js/timer.js`.
- Написана функция `tic()`, которая вычисляет время до конца текущего дня.
- В вёрстке используется семантический тег `<samp>` для плавной смены времени.
- Функция `tic()` вызывается каждую секунду через `setInterval`.
- Поиск элемента в DOM осуществляется через `document.getElementById('countdown')`.
- Изменение текста элемента происходит через свойство `textContent`.

## Технологии
- HTML5 (семантические теги)
- CSS3 (Flexbox, Grid, transitions, медиа-запросы)
- **JavaScript (ES6+, работа с DOM)**
- Animate.css 4.1.1
- WOW.js 1.1.2
- Font Awesome 6.5.2
- Google Fonts (Montserrat)
- Reset CSS 5.0.2

## Файлы
- `index.html` — разметка страницы;
- `css/main.css` — стили и адаптив;
- `js/timer.js` — логика таймера обратного отсчёта;
- `img/` — фотографии и изображения проектов.

## Контрольные точки адаптива
- **> 992px** — 3 карточки портфолио в ряд, фото и текст в хедере в одну строку;
- **768px–992px** — 2 карточки в ряд, хедер вертикальный;
- **< 768px** — 1 карточка в ряд, компактное меню;
- **< 480px / < 360px** — уменьшенные отступы, кнопки на всю ширину, боковые поля сохранены.
