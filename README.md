# Практическая работа №5 — адаптивный сайт-портфолио

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Свёрстан адаптивный сайт-портфолио **Харланович Алексей — фрилансер, веб-разработчик**.
Реализованы секции: главная, портфолио, контакты.

## Что реализовано
- **Фиксированное меню** с якорными ссылками (`Главная`, `Портфолио`, `Контакты`);
- **Hero-секция** с фотографией, именем, описанием и кнопками;
- **Секция портфолио** — три карточки реальных проектов (мебель, туризм, ЖК) через CSS Grid;
- **Секция контактов** — Telegram, Max, ВКонтакте с иконками Font Awesome;
- **Плавный скролл** (`scroll-behavior: smooth`);
- **Нативные CSS-анимации** — вращение логотипа, hover-эффекты кнопок с тенью и сдвигом;
- **Библиотечные анимации** — Animate.css + WOW.js (появление элементов при скролле);
- **Адаптив** от 1200px до 300px — с сохранением боковых отступов на всех разрешениях.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, transitions, медиа-запросы)
- Animate.css 4.1.1
- WOW.js 1.1.2
- Font Awesome 6.5.2
- Google Fonts (Montserrat)
- Reset CSS 5.0.2

## Файлы
- `index.html` — разметка страницы;
- `css/main.css` — стили и адаптив;
- `img/` — фотография и картинки проектов.

## Контрольные точки адаптива
- **> 992px** — 3 карточки портфолио в ряд, фото и текст в хедере в одну строку;
- **768px–992px** — 2 карточки в ряд, хедер вертикальный;
- **< 768px** — 1 карточка в ряд, компактное меню;
- **< 480px / < 360px** — уменьшенные отступы, кнопки на всю ширину, боковые поля сохранены.
