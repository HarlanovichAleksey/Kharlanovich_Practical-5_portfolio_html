# Практическая работа №5 — адаптивный сайт-портфолио

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Свёрстан адаптивный сайт-портфолио по макету **Portfolio**.
Реализованы:
- фиксированное меню с плавным скроллом (`Главная`, `Портфолио`, `Контакты`);
- hero-секция с фотографией, именем и кнопками призыва к действию;
- секция портфолио с карточками проектов (CSS Grid);
- секция контактов с иконками Font Awesome;
- адаптивная вёрстка под планшеты, мобильные и маленькие экраны;
- плавный скролл (`scroll-behavior: smooth`);
- эффект размытия навигации при наведении.

## Анимация
В проект добавлены:
- **Нативная CSS-анимация** (через `@keyframes`):
  - вращение иконки логотипа.
- **Библиотечная анимация** (Animate.css + WOW.js):
  - плавное появление элементов при скролле (`fadeInUp`, `fadeInLeft`, `fadeInRight`, `zoomIn`);
  - задержки для эффекта «каскада» у карточек.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, медиа-запросы)
- Font Awesome 6.5.2
- Google Fonts (Montserrat)

## Контрольные точки адаптива
- **> 992px** — 3 карточки портфолио в ряд, фото и текст в хедере в одну строку;
- **768px–992px** — 2 карточки в ряд, хедер вертикальный;
- **< 768px** — 1 карточка в ряд, компактное меню, уменьшенные отступы;
- **< 480px** — кнопки в столбик, мелкие заголовки.
